# Sales Performance Tracker Dashboard

## Overview

This Power BI dashboard provides insights into sales performance across product lines, cities, customer segments, payment methods, and branches.

## Key Metrics

* Sum of Total
* Sum of Quantity
* Sum of Tax 
* Sum of Unit Price

## Dashboard Features

* Product Line Performance Analysis
* City-wise Sales Analysis
* Gender-wise Customer Distribution
* Payment Method Analysis
* Product Line Distribution
* Interactive Filters for Product Line, Gender, Payment, and Branch

## Tools Used

* Power BI
* Excel

## Files Included

* Sales Performance tracker dashboard.pbix
* Sales_Performance_Tracker.png

## Insights

* Food and Beverages generated the highest sales.
* Sales performance can be compared across Naypyitaw, Yangon, and Mandalay.
* Customer distribution is analyzed by gender.
* Payment preferences are analyzed using Cash, Credit Card, and E-wallet transactions.
