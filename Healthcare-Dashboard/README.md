# Healthcare Dashboard

## Project Overview

This Power BI Healthcare Dashboard provides insights into patient records, admissions, billing, insurance providers, and demographic trends. The dashboard enables users to analyze healthcare data through interactive visualizations and slicers for better decision-making.

## Dashboard Highlights

### Key Performance Indicators (KPIs)

* Average Length of Stay: 15.51 days
* Average Patient Age: 51.54 years
* Hospital Records: 39.88K
* Total Patients: 55.50K
* Total Billing Amount: 1.42 Billion

### Visualizations

* Admission Trend Analysis (Monthly)
* Gender Distribution
* Admission Type Distribution
* Medication-wise Billing Amount
* Patients by Insurance Provider

### Interactive Filters

* Test Results
* Gender
* Admission Type

## Tools & Technologies

* Power BI
* Power Query
* DAX
* Data Modeling
* Data Visualization

## Business Insights

* Monitor patient admission trends over time.
* Analyze gender distribution among patients.
* Compare admission types such as Emergency, Elective, and Urgent.
* Evaluate billing contribution by medications.
* Identify leading insurance providers based on patient records.
