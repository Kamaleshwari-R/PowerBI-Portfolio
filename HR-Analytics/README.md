# HR Analytics Dashboard

## Overview

This Power BI dashboard provides insights into employee demographics, workforce distribution, and HR-related performance indicators.

## Objectives

* Analyze employee demographics
* Monitor workforce trends
* Track key HR metrics
* Support data-driven decision making

## Key Features

* Interactive KPI Cards
* Employee Distribution Analysis
* Department-wise Insights
* Workforce Demographics Visualization
* Dynamic Filters and Slicers

## Tools Used

* Power BI
* Microsoft Excel
